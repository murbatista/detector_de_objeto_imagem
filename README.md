# Detector de objeto em imagnes em Python

Projeto desenvolvido para praticar conceitos básicos
de programação em Python.

## Tecnologias
- Python

## Como executar
1. Clone o repositório.
2. Execute o arquivo detector_pasta_gatos.py.
3. ⚠️ Importante: A foto de conteúdo deve ter exatamente o nome conteudo.jpg
 e estar na raiz da pasta cat_images. Dentro da pasta minha_base_estilos/,
podes colocar quantas imagens quiseres (.jpg, .png, .jpeg).
